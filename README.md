# Airo for WordPress — Chat UI

Local interactive implementation of the Airo chat panel from Figma
(`Airo-for-WP-native-UI`, node `4470:442`).

Sending a message immediately shows the Airo Maui spinner (sparkles + ring)
before any reply text appears.

## Run

```bash
npm install
npm run dev
```

Open the URL Vite prints (default `http://localhost:5175`).
